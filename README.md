Bora 🚀

O Bora é uma plataforma criada para tornar as viagens de formatura mais acessíveis para estudantes e suas famílias.

🎯 Problema

Muitas famílias só começam a pagar pela viagem no 3º ano, enfrentando parcelas altas, juros, endividamento e, muitas vezes, a exclusão do aluno.

💡 Solução

O Bora permite:

💰 Poupar desde o 1º ano, com rendimento;
🤝 Conectar diferentes turmas para aumentar o poder de negociação;
🏷️ Usar leilão reverso entre agências para buscar melhores preços;
🧩 Montar a viagem de forma modular, de acordo com o orçamento.
👥 Público-alvo

Estudantes de 14 a 18 anos e seus pais ou responsáveis, principalmente das classes B, C e D.

📈 Modelo de negócio

A plataforma pretende gerar receita por meio de comissões sobre viagens, taxas das agências participantes e licenças para escolas.

🚧 Status

O projeto está em fase de ideação, com um protótipo inicial em desenvolvimento e planos de validação com alunos, famílias, escolas e agências.

Bora: transformar a viagem de formatura de um luxo de última hora em uma conquista planejada por todos.
